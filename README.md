# AM's Mystical Treasures

A Netlify-ready website starter for AM's Mystical Treasures LLC.

## Deploy to Ann's Netlify team

1. Push this folder to GitHub.
2. Ann invites you to her Netlify team with Developer access.
3. In that Netlify team, choose **Add new project** → **Import an existing project** → **GitHub**.
4. Select this repository and publish it. No build command is needed; the publish directory is `.`.
5. Attach `amsmysticaltreasures.com` in **Domain management** after Ann buys it.

## Local preview

Open `index.html` in a browser.
